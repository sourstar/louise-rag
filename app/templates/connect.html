Open WebUI, agents — Louise as a tool (MCP)

The program's own model decides when to search and writes the answer; Louise gives it three tools: louise_search, louise_lookup and louise_traverse. In Open WebUI: Admin Settings → External Tools → +, type MCP (Streamable HTTP), URL {{ base }}/api/ask/mcp, authentication Bearer with your key.

Scripts

An answer, as from any OpenAI client:

curl {{ base }}/v1/chat/completions \
  -H "Authorization: Bearer {{ key }}" -H "Content-Type: application/json" \
  -d '{"model": "louise", "messages": [{"role": "user", "content": "Who tilts at windmills?"}]}'

The ranked results alone, as the Ask tab gets them:

curl {{ base }}/api/ask/search \
  -H "Authorization: Bearer {{ key }}" -H "Content-Type: application/json" \
  -d '{"query": "Who tilts at windmills?", "limit": 10}'

Search fields: collections (names; default all), annotations, filters, limit, rerank_depth, as_of. Help explains each.
