#
#   - it is created by TODAY's platform, so its parser is today's (8): every

#     vectors are computed with, written out whole as RAGE states the run

#     engine loads through ${WEIGHTS} — the GGUF f16 of MedCPT, as in 02
#     §2.3's own worked example. The engine is outside space_id (02 §2.4);
#   - so its space is NOT the development collection's (version 2 hashed the
#     TEI image into space_id), and none of that collection's vectors is
#     admissible to it (§3.5). See docs/notes/v1-rebuild.md, "2026-09-21".
#

# medcpt-pubmed` possible — 22 of its 37 shards are still on the node), the
# calibration set, the layer, the origin and its form, the licence.
